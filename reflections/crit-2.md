# Crit 2 reflection — Unsolicited redesign

The new site was built to ensure consistency with the existing brand and
aligns cohesively with the current Squarespace website. The chosen colour
theme consists of black, white, and various shades of purple.

Based on research regarding website engagement and user retention, a suitable
template from Wix was adapted to complement Harmony's website, with specific
details integrated afterward. There were no permission restrictions regarding
the use of content or images from the original Squarespace site.

Key observations from the process:

1. The project required significant verification and attention to detail.
2. If too many tokens are used, switching to a manual process would help.
3. Making small, specific changes across the website is challenging.
4. Having a wireframe is highly beneficial.
5. Prompting can be a difficult trial-and-error process when experimenting.
6. A strong understanding of the technical terms is important.
